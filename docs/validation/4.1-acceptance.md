# KnowFlow 4.1 验收边界

## 自动门禁

```bash
npm run release:verify
git diff --check
shasum -a 256 -c artifacts/KnowFlow-4.1.0-SHA256SUMS
(cd artifacts && shasum -a 256 -c KnowFlow-4.1.0-PACKAGES-SHA256SUMS)
```

自动测试必须覆盖协议快照、完整编码与短编码、文档ID、无/合法/非法
frontmatter、BOM、CRLF、重复与 legacy 编码、预览过期、备份失败、批次
首/中/末项写入失败、重命名失败和索引失败。每条失败路径都要证明：

- 正文不丢失，文件名与 YAML 不分裂；
- 不发送成功同步事件；
- 错误指出失败对象，事务结果保留恢复位置。

UI 门禁要求只注册一套文件树右键入口和一个 KnowFlow Ribbon；采集、飞书拉取
和网页剪藏只返回 `proposalId`、`requiresConfirmation: true` 与
`protocolVersion`，不得直接编码。
