# KnowFlow 4.5.4 文件夹容器编码验收

## 目标

验证“父文件夹是容器”的目录编码规则：容器内直接子文件夹按去掉旧短编码后的名称自然排序，同一标签从 `01` 连续编号；不同容器独立计数。自动新建/改名和右键“整理此容器编码…”必须共用同一批量事务。

## 容器规则回归

- [x] 同一父目录的 `S07`、`S16` 按名称排序后变为 `S01`、`S02`。
- [x] 其他父目录已经使用 `S01` 时，新容器仍从 `S01` 开始。
- [x] 标签下拉只改变当前目标文件夹的标签；原标签组和新标签组都重新从 `01` 连续编号。
- [x] 容器目标路径冲突会阻断整组提交，不覆盖已有目录。
- [x] 临时换名或索引写入失败会恢复整组原路径和旧索引。
- [x] 导引、附件、隐藏目录、白名单和固定入口不参与容器编码。
- [x] 容器内 Markdown 内容、YAML 和链接不被目录批量改名逻辑写入。
