## 设计不变量

- 文件夹可见名称为 `TAGnn · 标题`；长编码 `YY_MMDD_TAG_NN` 只在 `.feishu-sync/目录编码索引.json` 中保存。
- 序号按标签全 Vault 使用 `01–99`；`Q → Z` 等手动改标签遇到目标序号占用时自动分配空闲序号，不覆盖其他目录。
- 白名单使用相对 Vault 路径，命中目录及子目录；根入口不编码，`🪧导引/`、`3️⃣附件文件/`、隐藏目录、`.obsidian`、`.feishu-sync`、`AGENTS` 永远保护；输入/知识池二级入口固定、三级起编，输出二级起编。
- 不在插件启动时批量改名旧文件夹；文件夹结构标签与 Markdown YAML 标签是两个独立动作。
- 索引写入使用临时文件改名；索引损坏时停止写入，不静默清空。
- 适配 Obsidian `DataAdapter.rename` 不覆盖已有目标的行为：替换前保存旧索引，目标占用时安全替换，失败恢复旧内容，不再循环提示 `Destination file already exists!`。
